## (C) tex ↔ docx 同步核查结论

**结论：docx 就是当前 tex 的编译产物。** 抽样 14 处、覆盖全部 Part（Introduction、I.C、II.B、II.C、II.D、II.F 条文 §2/§4/§9、II.G、III.A、III.B、IV.A、IV.D、V.A、V.C、Conclusion），措辞逐字一致，无一处实质差异。docx 标题层级（Heading 3/4/5 = Part/小节/小小节）与 tex 的 `\section/\subsection/\subsubsection` 完全一一对应，小节数量、顺序、标题文字均相同。

代表性比对（tex = docx 逐字）：
- 01 L21 = P0023；02 L39 = P0046；02 L55 = P0054；03 L28 = P0088；03 L59 = P0103；03 L141/145/159 = P0140/P0142/P0149；03 L195 = P0166；04 L9 = P0172；04 L96 = P0207；05 L34 = P0216；05 L96 = P0247；06 L10 = P0259；06 L34 = P0271；07 L7 = P0280。

**差异/注意事项（均非内容失同步）：**
1. **表格载体不同**：docx 中 Table 1（Material Control）与 Table 2（Relational Features）以**图片**嵌入（段落样式为 "Image Caption"）；只有 Table 3（control sheet）是原生 Word 表格。内容为图片的两表无法从文本提取层核对字面，但其标题与 tex caption 一致。
2. **脚注编号**：docx 脚注自 fn 15 起编（fn 1–14 应为扉页/摘要区脚注），加州 SB 243 脚注为 fn 145。worknote 的 "n. 19" 与当前编译稿不符。
3. **排版转换**：tex 的 `---`、` `` ''` 在 docx 中为 `—`、`“ ”`；tex 的 `\lrfootnote` 内容进入独立的 footnotes 层——均为正常编译产物。
4. **docx 多出的部分**：标题页、作者、摘要、关键词、目录（P0000–P0011）不在七个分 Part tex 文件内，应在主控 tex/preamble 中，非失同步。
5. worknote 本身与稿件的两处轻微错位（供修订时留意）：p. 22 引证归于 "Table 1"，实文在该表前后段落（03 L57、L83）；"n. 19" 脚注编号与当前 docx（fn 145）不一致。
